# GOALBALL LIVE v3

골볼 실시간 경기 기록과 경기·팀·선수 통합 분석.

- 실행: https://parabiomech.github.io/GOALBALL_LIVE/
- 이전 v2: https://parabiomech.github.io/GOALBALL_LIVE/v2/
- 이전 v1: https://parabiomech.github.io/GOALBALL_LIVE/v1.html

선수 등록 후 출발·릴리스·도착을 코트에 클릭하고 투구를 저장합니다. F/C/SB/LB 기술유형, 골 G·파울 L/H, 수기 시간, 선수교체·포지션 변경을 기록합니다. 전후반 코트 교대와 골대 기준 구역 1~6, 아웃 0/8 좌표를 지원합니다.

결과지는 상단 이벤트 타임라인과 팀별 투구 순서 시퀀스, 궤적·가우시안 히트맵을 제공합니다. 타임라인은 접고 펼칠 수 있습니다. 전체 결과지에서는 파일·폴더로 여러 경기를 읽고 각 요인을 복수 선택하며 통합 합계·팀별·선수별 전체 경기 히트맵을 표시합니다.

선수별 투구·골·득점률·파울 요약, 팀 내 투구 비율, 주요 도착 코스와 출발–릴리스–도착 패턴 상위 3개 및 비율을 제공합니다. 모든 분석은 선택 조건 기준이며, 코스·패턴 비율의 분모는 해당 선수 분석 투구입니다. 투구 0회일 때 득점률은 —입니다.

기록 파일명은 날짜·경기명을 포함합니다. 기록과 분석 라이브러리는 브라우저 안에 저장하며 영상이나 선수 기록을 서버로 전송하지 않습니다. 브라우저 저장만으로 백업을 대신하지 않으므로 JSON 파일로 저장해 보관하세요.
