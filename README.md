# 골볼 실시간 경기 기록

경기 등록에서 날짜·경기명·전반 왼쪽/오른쪽 팀명과 팀별 선수 번호·이름·L/C/R 포지션·출전 체크를 입력합니다. 팀마다 6칸이며, 체크한 현재 출전 선수만 기록 화면에 표시합니다. 출전 선수는 팀별 1~3명이며 포지션은 중복될 수 없습니다.

전반/후반 선택 → 출전 선수 선택 → 일반투구/페널티투구 선택 → 출발·릴리스·도착 클릭 → 투구 기록(Enter) 순서입니다. 투구를 저장한 뒤 기술유형 F/C/SB/LB와 골(G), 파울 L(L), 파울 H(H)을 각각 선택할 수 있습니다. 기술유형은 한 가지이며 결과와 별도로 저장합니다. 같은 버튼을 다시 누르면 해당 선택만 해제됩니다. 다음 투구에 기술유형은 자동으로 이어지지 않습니다. F/C/SB/LB와 L/H는 사용자 지정 코드로 보존합니다. 새 투구의 위치를 찍거나 선수를 바꾸면 직전 투구의 기술·결과 버튼은 비활성화됩니다. 최근 기록을 눌러 투구를 수정·저장한 다음 기술유형과 결과를 바꿀 수 있습니다. 기술유형은 최근 기록과 JSON의 technique 필드에 저장되며 기존 기록의 미선택 값도 유지합니다.

선수교체 버튼은 동일한 등록 창을 엽니다. 출전 체크와 포지션을 바꾸고 저장하면 교체 전후 명단, 전·후반, 시각, 경기 전체 몇 번째 투구 후 교체했는지를 기록합니다. 경기 등록 수정에서 명단을 바꿔도 교체 이력으로 남깁니다. 교체 이력은 JSON과 결과지의 펼침 목록에서 확인할 수 있습니다. 교체는 투구 수·득점률·히트맵에 포함하지 않습니다.

## 좌표와 코트

9m × 18m 코트를 오른쪽으로 90도 회전한 가로 화면입니다. 좌표는 가로 x=0~180, 세로 y=0~90이며 1단위는 10cm입니다. 아래쪽은 벤치입니다. 좌우 골대 모두 위에서 아래로 1~6구역이며 각 구역은 1.5m입니다. 가운데 선과 양쪽 골대는 파란색입니다. 클릭은 0.1단위로 반올림하며 y=90은 6구역에 포함합니다. 후반에는 두 팀의 코트 위치가 자동으로 바뀌고, 각 투구에 당시 전·후반을 저장합니다.

사진을 참고한 황토색 바닥과 구역선을 평면으로 그렸으므로 클릭 좌표에 원근 왜곡이 없습니다. 구역 점선은 분석용 보조선입니다.

## 결과지

위쪽 경기 구간(전체·전반·후반)·팀·선수·도착 코스·기술유형·이벤트 필터와 가로 코트 그림을 제공합니다. 경기 구간의 기본값은 전체이며 기록 화면의 전·후반 선택과 별개입니다. 선택 구간은 팀 합계·선수별 그림·득점률·구역 빈도·교체 이력에 적용합니다. 각 팀이 왼쪽에서 오른쪽으로 공격하도록 표시하며 오른쪽 코트의 투구는 x만 180-x로 반사하고 y는 유지해 벤치 기준 1~6구역을 보존합니다. 팀 합계는 선수 필터와 관계없이 해당 팀 전체를 합산하며, 나머지 필터는 적용합니다. 그 아래에는 선수별 그림을 표시합니다. 기술유형은 전체·F·C·SB·LB·미선택으로 고를 수 있으며 팀 합계와 선수별 그림·통계에 함께 적용합니다. 이전 기록의 누락된 기술유형도 미선택으로 포함합니다. 교체 이력에는 기술유형을 적용하지 않습니다. 이벤트 필터의 일반투구/페널티투구는 투구 유형이며 골/파울은 결과입니다.

출발→릴리스는 회색 점선, 릴리스→도착은 진한 실선입니다. 선은 기록한 지점을 연결하며 실제 공 추적 결과는 아닙니다. 가우시안 커널(σ=7단위, 0.7m)을 알려진 세 위치에 동일 가중치로 합산합니다. 표시된 팀·선수 그림은 공통 최댓값으로 정규화하며 필터 변경 시 범위도 다시 계산합니다.

그림 아래에는 골·파울·득점률과 도착 1~6구역의 횟수 및 비율을 표시합니다. 득점률은 골/전체 기록 투구(파울 포함)입니다. 빈도의 분모는 해당 그림의 전체 기록 수입니다.

## 저장 및 배포

브라우저 localStorage에 자동 저장하며 메뉴에서 JSON 저장·불러오기를 지원합니다. 새 형식은 schemaVersion=4입니다. 이전 형식은 좌표와 결과를 보존해 가져옵니다. 기존 기록에는 전·후반 정보가 없으므로 전반으로, 유형은 일반투구로 유지하며 이전 파울은 L/H를 추측하지 않고 미분류로 표시합니다. v1/v2 좌표는 시계 방향으로 회전하며 출발은 미확인입니다. 기존 v3의 실제 좌우 코트 기록도 결과지에서 정리합니다. 이전 자동 저장 키는 보존합니다. 가져온 경기의 출전 체크와 포지션은 등록 화면에서 지정해야 합니다.

`index.html`, `styles.css`, `app.js`, `.nojekyll`을 GitHub Pages 저장소 루트에 올리고 main 브랜치의 루트에서 배포합니다. 외부 라이브러리·서버·LLM 호출 없이 작동합니다. 경기 기록은 사용 중인 브라우저에 저장되며 GitHub에 전송되지 않습니다. 다른 기기 또는 로컬 주소에서 공개 사이트로 옮길 때 JSON 저장·불러오기를 사용하세요.
